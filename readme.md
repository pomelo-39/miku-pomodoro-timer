# Miku Pomodoro Timer

勉強と休憩を自動で切り替えるポモドーロタイマーアプリです。

---

## 主な機能

- **ポモドーロ・サイクル**: 勉強時間（25分）と休憩時間（5分）を自動でループ。

---

## 使用技術 (Tech Stack)

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS)
- **Infrastructure**: Docker (Nginx / Alpine)
- **Development Environment**: WSL2 (Ubuntu), VS Code, Git / GitHub
